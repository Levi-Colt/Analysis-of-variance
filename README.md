# Analysis-of-variance
Exercise in conducting analysis of variance in R

GEO 411 HW 2

Overview:This assignment looked at the same precipitation data that was used and the first homework assignment. This assignment was an exercise in analysis of variance using a variety of different tests. These tests included ANOVA, Kruskal-Wallis, Levene, K-S, and Median tests. After the statistics were calculated using R, a six step hypothesis test was conducted to analyze the results of these statistics.

Methods: R, ANOVA, Kruskal-Wallis, Levene, K-S, Median

Key Findings:The results of the hypothesis test indicated statistically significant changes in the Buffalo climate between 1967 & 1997.

Tools: RStudio

Reflection: When analyzing data to detect moments of change, there are many factors to consider, as well as tests to conduct, before determining whether or not changes in the data are statistically significant.
